# OpenRoot Developer Program

Building an open-source project, or have an idea for one? Apply to join the OpenRoot Developer Program for free project visibility and a chance to earn rewards for reviewed milestones.

The OpenRoot Developer Program brings independent developers, called **OpenRoot builders**, together with partners who want to support useful software. Builders develop and grow projects under the **OpenRoot GitHub organization**. OpenRoot helps promote member projects through its publication and social channels, **completely free of charge** and as much as it can. Coverage, reach and success are not guaranteed. Partners supply credits, subscriptions, and developer tools for qualifying projects.

Promotion is not limited to one feature. Projects may appear multiple times in the newsletter and on social channels through project highlights, showcases and in-depth articles. Builders can send releases, substantial updates and user stories to hello@openroot.dev for editorial consideration. This support is completely free of charge and does not require earning or redeeming a reward. Timing and format depend on editorial fit and available capacity; OpenRoot does not guarantee repeat coverage, reach or results.

To suggest a feature, email hello@openroot.dev with your project or release link, who it helps, what changed, the specific points you would like highlighted, and optional screenshots or a demo you have permission to share. OpenRoot manually drafts the final post to fit its editorial standards and each platform. A request is not required: OpenRoot may also feature public member-project updates on its own initiative. Do not send credentials, confidential material or other people's personal data. This is an email process; a dedicated portal request form is not available yet.

We are looking for builders creating, or exploring, projects intended for other people to use: software that solves a problem, provides a useful tool or helps its users do something. Any software category, programming language and documentation language is welcome. Your project does not need existing users, and undecided applicants or an agreed private development phase remain welcome.

Hackathon builders are welcome too, whether preparing to enter or continuing a hackathon project. Additional rewards for strong results in eligible, pre-approved hackathons are planned. Eligible events, outcomes, evidence, funding and bonus terms must be published and agreed before a reward-bearing offer begins. A win does not automatically earn OpenRoot points or a reward. No specific eligible hackathons or bonus amounts are announced yet; hackathon bonus claims are not open.

You retain rights to your own code and lead your project. Your repository is hosted under OpenRootdev, with repository-level Admin for the member who creates it or brings it in through an approved transfer. This is not a work-for-hire arrangement or a blanket transfer of code rights.

Existing organization members can create new repositories without another application or separate OpenRoot approval. New repositories created from scratch automatically join the program, subject to its policies. OpenRoot manually reviews repositories and contacts the repository admin if changes or removal are needed. Policy bots are planned as the organization grows; they are not active yet. Program enrollment does not automatically approve rewards: private projects must become public and meet the agreed milestone and funding conditions before earning rewards.

Your project is not exclusive to OpenRoot. You can enter hackathons, collaborate elsewhere and take part in other activities, subject to those activities' rules and your project rights.

## A free sandbox. Keep your accounts safe.

OpenRoot is a sandbox for building and collaborating, not a payment request. We will never ask you to send passwords, sign-in or recovery codes, access tokens, API keys, payment details or a fee to join or unlock rewards. Applications need your email and exact GitHub username; enter a sign-in code only on the official portal, never send it to a person. You can invite collaborators and configure repository-scoped apps within your repository permissions; some organization-level actions need an owner. Keep secrets out of repos, applications and messages. Organization hosting is not unlimited free use of paid services.

Questions: [hello@openroot.dev](mailto:hello@openroot.dev). [Follow or message OpenRoot on LinkedIn](https://www.linkedin.com/company/openroot-dev/). After accepting the GitHub invitation, read the [members-only quick start](https://github.com/OpenRootdev/GET-STARTED-README).

## Existing projects belong in the organization

If you apply with an existing project, the accepted project must be hosted under **OpenRootdev**: transfer the original repository after review, or create an empty organization repository and copy the code there with Git. Do not migrate before the project and migration are approved. Copying code does not copy stars, issues or other GitHub project data. Existing adoption and rewards are reviewed separately. [Read the step-by-step builder instructions](docs/builders.md).

## Join the community without joining the program

You can join the OpenRoot community without applying to the developer program. At https://openroot.dev/community, verify your GitHub account, choose an optional interest and agree to the community rules. The privacy notice is available to read, without a separate checkbox. This requests an ordinary organization invitation for the Community team only. Accept it on GitHub to finish joining. It does not create a portal account, subscribe you to the newsletter or make a repository eligible for rewards. Community members may create repositories under the organization's existing settings and can apply to the developer program later.

Community joining records your verified GitHub ID and username, optional interest, community-rules acceptance, joining request, privacy-notice version and invitation status privately in Finland for up to 12 months. A necessary secure browser cookie binds GitHub verification to your browser for up to 10 minutes. GitHub handles authorization and invitation acceptance under its own policies; OpenRoot does not ask you to send a password, sign-in code or access token. Optional website analytics are not collected on the joining or callback pages. Contact hello@openroot.dev for access, correction, deletion or membership help. Hosting services handle technical request logs.
