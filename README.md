# OpenRoot Developer Program

Get rewarded for the projects you are already building.

The OpenRoot Developer Program brings independent developers, called **OpenRoot builders**, together with partners who want to support useful software. Builders develop and grow projects under the **OpenRoot GitHub organization**. OpenRoot helps promote member projects through its publication and social channels, **completely free of charge** and as much as it can. Coverage, reach and success are not guaranteed. Partners supply credits, subscriptions, and developer tools for qualifying projects.

Bring your own ideas in any software category, programming language or repository/documentation language, including non-English content. You direct your project and retain rights to your own code. A private development phase is welcome; any public-release conditions are agreed before enrollment. Organization owners retain administrative access to organization-hosted repositories.

Your project is not exclusive to OpenRoot. You can enter hackathons, collaborate elsewhere and take part in other activities, subject to those activities' rules and your project rights.

## Current status

The program is **live**. We are seeking founding partners. [Applications are open for review](https://openroot.dev/apply); the private portal is available to approved accounts at https://openroot.dev/portal; reward claims are not open; numerical milestones and final fulfillment terms are being prepared. OpenRoot reports an initial set of offers: one month of DeepLearning.AI (one available until claimed), and AI model API credits for GPT, Claude, Gemini and Grok, delivered through budget-limited third-party API access, valued at EUR 50-1,000. The API allowances have per-key budget limits, with no announced quantity cap. Exact learning product, permitted distribution, expiry and recipient terms still need confirmation. These are not official model-provider sponsorships or guaranteed rewards for every member. A broader selection, including paid subscriptions and developer tools, is coming soon; specific offers and dates are not promised. See [reward details](docs/rewards.md).

This repository is the public documentation home. It explains the program, answers questions, and invites partnerships. It does not contain the private portal application or applicant records.

## Help builders keep building

We welcome partners who can provide AI or cloud credits, paid tool access, or other useful developer benefits. Start with a bounded pilot and support projects that demonstrate genuine traction.

[Partner with us](https://openroot.dev/partners), or email **partner@openroot.dev**. The website's partner form prepares an email draft locally; it is not a server-side submission.

For general questions, contact [hello@openroot.dev](mailto:hello@openroot.dev).

Documentation corrections and questions are welcome through [repository issues](https://github.com/OpenRootdev/developer-program/issues). Do not post personal application details, security reports, credentials, or reward redemption codes publicly.

## A free sandbox. Keep your accounts safe.

OpenRoot is a sandbox for building and collaborating, not a payment request. We will never ask you to send passwords, sign-in or recovery codes, access tokens, API keys, payment details or a fee to join or unlock rewards. Applications need your email and exact GitHub username; enter a sign-in code only on the official portal, never send it to a person. You can invite collaborators and configure repository-scoped apps within your repository permissions; some organization-level actions need an owner. Keep secrets out of repos, applications and messages. Organization hosting is not unlimited free use of paid services.

Questions: [hello@openroot.dev](mailto:hello@openroot.dev). [Follow or message OpenRoot on LinkedIn](https://www.linkedin.com/company/openroot-dev/). After accepting the GitHub invitation, read the [members-only quick start](https://github.com/OpenRootdev/GET-STARTED-README).

## Existing projects belong in the organization

If you apply with an existing project, the accepted project must be hosted under **OpenRootdev**: transfer the original repository after review, or create an empty organization repository and copy the code there with Git. Do not migrate before the project and migration are approved. Copying code does not copy stars, issues or other GitHub project data. Existing adoption and rewards are reviewed separately. [Read the step-by-step builder instructions](docs/builders.md).
