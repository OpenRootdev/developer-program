# Cómo funciona el programa

El programa recompensa el éxito del proyecto con beneficios no monetarios. No paga por horas, commits ni simplemente iniciar un repositorio.

## Solicitar

Envía correo y usuario GitHub exacto mediante el formulario en https://openroot.dev/apply. Una idea o enlace a un proyecto existente ayuda a la revisión. Solicitar no implica aprobación ni compromiso de recompensa.

## Obtener aprobación y verificar identidad

OpenRoot revisa la solicitud. El flujo previsto de aprobación creará tu cuenta e iniciará la adhesión GitHub. El portal privado y el aprovisionamiento automático aún no están implementados; las solicitudes iniciales se guardan para revisión manual. En el primer acceso, verifica el correo aprobado y vincula el GitHub que controlas. Solo cuentas aprobadas acceden al portal. La pertenencia y los accesos siguen acotados.

## Construir y crecer

Crea un proyecto aprobado dentro de OpenRoot y acuerda su vía de éxito. Gestionas desarrollo, mantenimiento y marketing general. OpenRoot ayuda a promocionar los proyectos miembros en su publicación y redes, totalmente gratis y tanto como pueda, sin garantizar cobertura, tráfico o adopción. Puedes participar en hackathons y actividades externas.

## Mostrar avances

El portal previsto reúne repositorios asociados, contribuciones, versiones y pruebas. Las métricas indican fuente y periodo. Usuarios y descargas de paquetes requieren fuentes aparte de GitHub.

## Alcanzar un hito

Presenta las pruebas exigidas por las reglas de tu proyecto. OpenRoot comprueba resultados, periodo y actividad excluida. Superar un umbral puede iniciar la revisión; no entrega la recompensa automáticamente.

## Elegir una recompensa confirmada

Si la solicitud cumple las condiciones de una cohorte financiada, elige una opción elegible del catálogo disponible. El registro sigue aprobación y entrega. OpenRoot comunica [las ofertas iniciales](rewards.md), pero las condiciones y solicitudes no están finalizadas ni abiertas. Una oferta no crea un derecho automático para todos.

Lee [las reglas](rewards.md), [la guía](builders.md) o [las preguntas frecuentes](faq.md).
