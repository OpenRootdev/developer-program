# マイルストーンと報酬

開発を続けるための非現金特典です。確認済みパートナーシップか、明確に資金を確保した参加グループを通じて提供します。

## 何を評価するか

プロジェクトに合った成果の評価経路を使います。

- 注目：自然に獲得した GitHub スター、意味のある外部関心、掲載。
- 配布：定義した期間内のリリース・パッケージダウンロード、完全クローン、コンテナイメージの取得。
- 利用：合意した意味のある製品利用アクションで測定する日間・月間アクティブユーザー（DAU/MAU）。
- 継続利用：適切な利用指標が一定期間維持されること。

利用の証拠にはイベント、ユニークユーザーの定義、測定期間、データ源を示す必要があります。GitHub リポジトリだけでは製品のユーザー数を測定できません。ビルダーが承認した、プロジェクト単位の PostHog 等の集計レポートを審査に利用できます。ボット、テスト、不自然な活動を除外し、DAU/MAU とダウンロード数を同一視せず、重複する利用を二重計上しません。適切な利用者への通知、必要な同意、アクセス管理の下でのみデータを収集・共有してください。指標によってポイントや報酬が自動的に発生することはありません。

スターは関心、ダウンロードは配布の指標です。どちらも自動的にアクティブユーザーを意味しません。反復自動処理、購入した反応、自作の水増しでは実績を示せません。具体的除外条件は各グループで公開します。

## ポイントとマイルストーン請求 / 試行ルール、2026年10月18日

初期のレベルでは対象となる新規の自然な GitHub スター1件あたりのポイントを多くし、成長に伴い追加スターの付与率を徐々に下げます。以下のマイルストーンに達して手動審査を通過した場合のみポイントを利用でき、途中の任意の数では請求できません。非現金の報酬ポイントであり、モデルのトークンや譲渡可能な残高ではありません。

| マイルストーンレベル | 対象スター数 | 利用可能な累計ポイント | 前のマイルストーンからの追加ポイント |
|---|---:|---:|---:|
| 1 | 20 | 800 | 800 |
| 2 | 50 | 1700 | 900 |
| 3 | 100 | 3000 | 1300 |
| 4 | 250 | 6000 | 3000 |
| 5 | 500 | 10000 | 4000 |
| 6 | 1000 | 12500 | 2500 |
| 7 | 2500 | 17500 | 5000 |
| 8 | 5000 | 22500 | 5000 |

**20 スターで 800 ポイントを利用できます。** 7件や19件では請求できず、30件では20件のマイルストーンのみ対象です。800ポイントを受領済みで50件に達すると追加は900ポイント、合計1700であり、全額の再付与ではありません。早期の請求を飛ばしても対象ポイントは失われず、同じプロジェクトと経路で付与済みの全ポイントを差し引きます。5000件を超えるレベルは未公表です。既存の合意済み報酬を自動的に減額・再計算しません。旧ルールからの変更には明示的な合意と付与済みポイントの照合が必要です。

この表は合意した基準からの対象となる新規成長に適用し、表示される全スターの自動換算ではありません。報酬付き参加前に指標、出典、基準、計測開始・期間、証拠、資金が確保された上限と特典条件を合意します。過去のスターは別途合意が必要で、過去分の割引率は未公表です。報酬は合意したプロジェクト・チームに配分し、協力者ごとに重複付与しません。ボット、購入した反応、自分やチームによる水増し、スターの付け外し、コピーや計数間の重複を除外します。付与済みポイントの再付与や、有効な過去の合意・受諾済み申請版の遡及変更はしません。

**ダウンロード：** 対象となるリリース・パッケージのダウンロード100件は10ポイント（USD 1）に相当します。蓄積開始前に出典ごとの請求しきい値、期間、除外を合意する必要があり、この目安だけで任意の数を請求できません。閲覧、完全クローン、コンテナ pull は自動的な報酬対象でも製品 DAU/MAU でもありません。有意義な DAU/MAU は審査の証拠にできますが、標準ポイント比率は未公表です。移転したプロジェクトでは合意した開始時点から対象となる新規ダウンロード・利用を数え、最初の請求は1か月後に審査を条件として可能になります。移転前の履歴を新規活動とは扱いません。

**手動請求を受け付けています。** Organization 内のリポジトリ URL、到達したマイルストーン、日付付き証拠、過去の請求を hello@openroot.dev に送ってください。OpenRoot が証拠を審査し、付与済みポイントを差し引き、利用可能な特典と条件を確認して、承認後に交換を手配します。最初の承認済みスターマイルストーンは次のレベルを待たずに交換できますが、移転時に合意した待機期間には従います。現在の API 換算は10ポイント = USD 1の非現金 API 利用枠であり、現金残高や今後の全特典に約束された比率ではありません。ポータルの自動ウォレットやセルフサービス交換はまだありません。API キーやアカウントのパスワードは送らないでください。

## 特典の種類

AI/API 利用、GPU・クラウド、サブスクリプション、IDE、開発ツールなどです。Builders が対象となる利用可能な選択肢から選ぶ方針です。

### OpenRoot が報告する初期特典 / 2026年10月18日

- **DeepLearning.AI：**1か月分。**受け取りが確定するまで1件のみ利用可能**です。正確な製品と受取条件は確認待ちです。
- **AI モデル API クレジット：** **USD 20-10,000** 相当の利用枠で、**GPT-6 Astra、Claude Fable 5.1、Gemini 4 Argon のモデル系列**に対応します。OpenRoot によれば各提供キーに厳格な予算上限があります。**特典数の上限は公表していません**が、無制限の支出や各人への USD 10,000 自動付与ではありません。配布許可、有効期限、モデル、資格、提供方法は発行前に確認します。第三者経由の利用であり、自分の OpenAI/Anthropic/Google/xAI アカウントへのクレジット移転でも、各社の公式スポンサーシップでもありません。
- **有料サブスクリプションや開発ツールを含む追加特典を近日予定しています。**具体的な製品、数量、日付は約束しません。

パートナーが現在利用可能と報告しているモデルは **GPT-6 Astra、Claude Fable 5.1、Gemini 4 Argon** です。各承認済み特典で利用可否を確認します。後継モデルは API 公開後、パートナーの対応、プロバイダーの条件、同程度の価格が揃う場合に切り替える方針ですが、公開当日の更新は保証しません。価格や条件の大幅な変更によりモデル一覧が変わり、API 利用枠が一時的に提供できない場合があります。承認済みの未使用ポイントは記録を保持し、合意条件に従って他の対象となる利用可能な特典に交換できます。現金ではなく、代替特典の在庫や即時交換を保証しません。カタログ更新によって既存の合意済み報酬を取り消しません。

販売元の身元は非公開です。必要な受取人への開示、配布許可、有効期限、提供条件は発行前に特典ごとに確認します。文書、申請、公開 issues に API キー、交換コード、認証情報を投稿しないでください。個人アカウント共有やプロバイダーキー移転は約束しません。builders のマイルストーン手動請求は受付中ですが、アフィリエイトへの提供は別の手続きで、自動的には有効になりません。

各特典はアカウント資格、サービス・期間・金額、有効期限、受取期限、継続請求義務を開示します。OpenRoot はパスワードを求めたり共有有料アカウントを配布したりしません。

## 報酬の選択と利用

マイルストーンと請求が承認された後、builders はプロジェクトや参加グループで対象となる利用可能な特典から選べます。金額、モデル、条件は各特典で確認します。USD 20-10,000 は全員に最高額を自動付与する意味ではありません。可能な限り行う完全無料の宣伝は別の会員特典で、報酬を消費しません。

プロジェクトの宣伝は1回の紹介に限定されません。ニュースレターや SNS で、プロジェクトの注目ポイント、作品紹介、詳しい解説記事として複数回取り上げられる場合があります。Builders はリリース、大きな更新、ユーザーの活用事例を hello@openroot.dev に送り、編集側での検討を依頼できます。この支援は完全無料で、報酬の獲得や交換は必要ありません。時期と形式は編集上の適合性と対応可能な範囲によって決まります。OpenRoot は再掲載、リーチ、成果を保証しません。

OpenRoot は、他の人が使うことを目的としたプロジェクトを開発、または検討している builders を求めています。問題を解決するソフトウェア、便利なツール、ユーザーが何かを実現するためのソフトウェアなどが対象です。ソフトウェアの分野、プログラミング言語、ドキュメントの言語は問いません。既存ユーザーは必要ありません。まだアイデアが決まっていない申請者や、合意した非公開の開発期間も歓迎します。

参加を準備している方や、ハッカソンのプロジェクトを継続している方も歓迎します。対象として事前承認されたハッカソンでの優れた成果に対する追加報酬を計画しています。対象イベント、成果、証拠、資金、ボーナス条件は、報酬付きの募集を始める前に公開し、合意する必要があります。優勝しても OpenRoot のポイントや報酬が自動で付与されるわけではありません。具体的な対象ハッカソンやボーナス額はまだ公表しておらず、ハッカソン追加報酬の請求はまだ利用できません。

Hermes、OpenClaw、OpenCode はカスタムプロバイダーや OpenAI 互換エンドポイントに対応しますが、実際の報酬ゲートウェイでこれらのクライアントをまだ検証していません。Cursor の自前キーによるチャットはクライアント・モデル・ゲートウェイの検証が必要です。クレジットに Cursor サブスクリプションや Tab は含まれません。Codex は Responses API、ストリーミング、ツール呼び出しを伴う会話への対応が必要です。Claude Code は Anthropic Messages など、対応するゲートウェイ API 形式が必要です。OpenAI Chat Completions だけの互換性では Codex や Claude Code への対応を証明できません。受取前にエンドポイント、モデル ID、クライアント制限、受取人のプライバシー条件を確認します。

[Codex のゲートウェイ要件](https://learn.chatgpt.com/docs/enterprise/gateway-compatibility)と[Claude Code の要件](https://code.claude.com/docs/en/llm-gateway-protocol)を参照してください。この草案はエンドツーエンドの互換性を約束しません。

## 資金と公平性

報酬付きグループへの参加前に報酬と資金を確認します。未資金の関心リストは報酬を約束しません。在庫制限がある場合、定員と予約規則を最初から明確にします。

条件達成者への保証特典と、審査型・枠制限付き賞を区別します。有効な請求を拒むため規則を遡って変えません。既存プロジェクトの基準値や過去実績の扱いは参加前に決めます。

プロジェクト・チーム合意で配分し、全貢献者への自動倍増はありません。請求は提出、審査、承認、発行へ進みます。販売元が確認しなければ受取状況が不明な場合があります。訂正や再審査を求められます。

非現金特典にも適切な会計処理と、報酬提供前の管轄別確認が必要です。本草案は税務処理を定めません。
