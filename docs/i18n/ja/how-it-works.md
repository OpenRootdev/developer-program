# プログラムの仕組み

プロジェクトの成功に対して非現金特典を提供します。作業時間、コミット数、リポジトリ作成だけに報酬を支払いません。

## 申請

https://openroot.dev/apply でメールと正確な GitHub 名を提出します。アイデアや既存プロジェクトのリンクは審査に役立ちます。申請は承認や報酬の約束ではありません。

## 承認と本人確認

承認すると、参加手続きが未完了のポータルアカウントを作成し、案内メールを送ります。承認されたメールアドレスで https://openroot.dev/portal にログインし、届いたコードはそのページだけに入力してください。Kristofer はポータルアカウントを承認する前に GitHub Organization の招待を手動で送ります。承認後、招待の承認と Organization 内でのリポジトリ作成手順をまとめた歓迎メールを1通だけ送ります。GitHub 身元の自動連携、プロジェクト指標、ポータルの自動報酬請求はまだ利用できません。未完了アカウントの期限は申請時の90日間から延長されません。承認だけで資金が確保された報酬を得られるわけではありません。

## 開発と成長

既存メンバーは、再申請や OpenRoot の個別承認なしで新しいリポジトリを作成できます。ゼロから作成した新規リポジトリは、ポリシーに従うことを条件に自動的にプログラムへ参加します。OpenRoot が手動で確認し、修正や削除が必要な場合は管理者に連絡します。規模の拡大に合わせてポリシー確認 bot を導入する予定ですが、まだ稼働していません。参加だけで報酬が承認されるわけではありません。非公開プロジェクトが報酬を得るには、公開し、合意したマイルストーンと資金条件を満たす必要があります。

開発者は開発、保守、広範な宣伝を担当します。OpenRoot は刊行物と SNS で完全無料の紹介を可能な限り行いますが、掲載、流入、利用を保証しません。ハッカソンや外部活動にも参加できます。

プロジェクトの宣伝は1回の紹介に限定されません。ニュースレターや SNS で、プロジェクトの注目ポイント、作品紹介、詳しい解説記事として複数回取り上げられる場合があります。Builders はリリース、大きな更新、ユーザーの活用事例を hello@openroot.dev に送り、編集側での検討を依頼できます。この支援は完全無料で、報酬の獲得や交換は必要ありません。時期と形式は編集上の適合性と対応可能な範囲によって決まります。OpenRoot は再掲載、リーチ、成果を保証しません。

紹介を提案するには、プロジェクトまたはリリースのリンク、誰に役立つか、変更点、特に取り上げてほしい具体的なポイントと、共有する権限のある任意のスクリーンショットやデモを hello@openroot.dev にメールで送ってください。OpenRoot が編集基準と各プラットフォームのスタイルに合わせて、最終的な投稿を手作業で作成します。依頼は必須ではありません。OpenRoot が独自にメンバーのプロジェクトの公開アップデートを取り上げることもあります。認証情報、機密資料、他の人の個人データは送らないでください。現在はメールで受け付けており、ポータルの専用依頼フォームはまだありません。

## 進捗を示す

将来のポータルは関連リポジトリ、貢献、リリース、達成証拠をまとめます。指標には出典と測定期間を表示します。ユーザー数やパッケージのダウンロードには GitHub 以外の証拠が必要です。

## マイルストーン達成

合意した規則に必要な証拠を提出します。OpenRoot は成果、期間、除外活動を確認します。閾値到達で審査が始まる場合がありますが、報酬は自動発行しません。

## 確認済み報酬を選ぶ

資金付きグループの条件を満たした申請は、利用可能な非現金特典から対象の選択肢を選べます。記録で承認と提供を追跡します。OpenRoot が報告する[初期特典](rewards.md)のマイルストーン手動請求は受付中で、特典の条件は発行前に確認します。特典の掲載は全員の自動受給権を意味しません。

[報酬ルール](rewards.md)、[参加ガイド](builders.md)、[FAQ](faq.md)をご覧ください。
