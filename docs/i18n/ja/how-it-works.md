# プログラムの仕組み

プロジェクトの成功に対して非現金特典を提供します。作業時間、コミット数、リポジトリ作成だけに報酬を支払いません。

## 申請

https://openroot.dev/apply でメールと正確な GitHub 名を提出します。アイデアや既存プロジェクトのリンクは審査に役立ちます。申請は承認や報酬の約束ではありません。

## 承認と本人確認

OpenRoot が申請を審査します。予定の承認処理ではアカウントを作成し、GitHub 加入手続きを始めます。非公開ポータルと自動開通はまだ実装されておらず、現在の申請は手動審査用に保存します。初回ログイン時に承認済みメールを確認し、自分が管理する GitHub を連携します。承認済みアカウントだけがポータルに入れます。所属とプロジェクトアクセスは限定範囲のままです。

## 開発と成長

Organization 内で承認済みプロジェクトを作り、成果の評価方法を合意します。開発者は開発、保守、広範な宣伝を担当します。OpenRoot は刊行物と SNS で完全無料の紹介を可能な限り行いますが、掲載、流入、利用を保証しません。ハッカソンや外部活動にも参加できます。

## 進捗を示す

将来のポータルは関連リポジトリ、貢献、リリース、達成証拠をまとめます。指標には出典と測定期間を表示します。ユーザー数やパッケージのダウンロードには GitHub 以外の証拠が必要です。

## マイルストーン達成

合意した規則に必要な証拠を提出します。OpenRoot は成果、期間、除外活動を確認します。閾値到達で審査が始まる場合がありますが、報酬は自動発行しません。

## 確認済み報酬を選ぶ

資金付きグループの条件を満たした申請は、利用可能な非現金特典から対象の選択肢を選べます。記録で承認と提供を追跡します。OpenRoot が報告する[初期特典](rewards.md)の提供・請求条件は未確定で、受付も未開始です。特典の掲載は全員の自動受給権を意味しません。

[報酬ルール](rewards.md)、[参加ガイド](builders.md)、[FAQ](faq.md)をご覧ください。
