# Builder 紹介プログラム

開始前計画、2026年10月11日。未稼働で、資金付き紹介特典や請求ツールは未確認です。

## 実際のマイルストーンに到達する builders を紹介

紹介された builder が承認され、対象プロジェクトの検証済みマイルストーンを達成した後に紹介を評価します。申請、登録、リポジトリ作成だけでは足りません。

自分のアイデアを作りたい人に[ガイド](https://openroot.dev/program)を共有してください。受付開始後、申請者は紹介者の正確な GitHub 名を入力できます。連絡先の一括アップロードや自動招待は予定しません。

所属、プロジェクト、紹介の帰属、証拠、資金付き紹介報酬をそれぞれ審査します。紹介は承認を省略しません。新規・承認済み既存プロジェクトには同じ公開規則を適用します。

## 公平な帰属

記入されたユーザー名は申告であり、本人確認ではありません。帰属を確認し検証済み ID に結び付けます。重複や紛争は審査します。自己紹介、自動化アカウント、重複アカウント、利用量の操作は対象紹介を増やせません。

紹介者に他の builder の非公開データへのアクセスを与えません。表示状況は開示済み情報と合意権限に限定します。

## 開始前の資金と条件

特典候補は許可されたクレジット、サブスクリプション、ツールです。選択肢、紹介者資格、目標、上限、帰属時点、異議申立て、チーム、定員、受取規則を参加前に公開し資金を確保します。数量や閾値は未公表です。

紹介報酬はプロジェクト自身の報酬と別です。リンク共有、Organization 加入、既存リポジトリ移転でどちらも約束しません。過去の成果は承認済みグループが明示的に認めた場合だけ対象です。

[紹介ガイド](https://openroot.dev/referrals)、[builders](builders.md)、[報酬](rewards.md)、[パートナー](partners.md)をご覧ください。
