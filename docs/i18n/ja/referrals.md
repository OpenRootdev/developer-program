# Builder 紹介とアフィリエイト試行

以前の GitHub ユーザー名による builder 紹介案は、稼働中の報酬制度ではありません。以下の独立したアフィリエイト試行は2026年10月14日から審査用申請を受け付けます。アフィリエイトのセルフサービス報酬交換はまだ利用できません。

## 実際のマイルストーンに到達する builders を紹介

紹介された builder が承認され、対象プロジェクトの検証済みマイルストーンを達成した後に紹介を評価します。申請、登録、リポジトリ作成だけでは足りません。

自分のアイデアを作りたい人に[ガイド](https://openroot.dev/program)を共有してください。申請受付中で、申請者は紹介者の正確な GitHub 名を入力できます。連絡先の一括アップロードや自動招待は予定しません。

所属、プロジェクト、紹介の帰属、証拠、資金付き紹介報酬をそれぞれ審査します。紹介は承認を省略しません。新規・承認済み既存プロジェクトには同じ公開規則を適用します。

## 公平な帰属

記入されたユーザー名は申告であり、本人確認ではありません。帰属を確認し検証済み ID に結び付けます。重複や紛争は審査します。自己紹介、自動化アカウント、重複アカウント、利用量の操作は対象紹介を増やせません。

紹介者に他の builder の非公開データへのアクセスを与えません。表示状況は開示済み情報と合意権限に限定します。

## 紹介特典の提供前に必要な資金と条件

特典候補は許可されたクレジット、サブスクリプション、ツールです。選択肢、紹介者資格、目標、上限、帰属時点、異議申立て、チーム、定員、受取規則を参加前に公開し資金を確保します。数量や閾値は未公表です。

紹介報酬はプロジェクト自身の報酬と別です。リンク共有、Organization 加入、既存リポジトリ移転でどちらも約束しません。過去の成果は承認済みグループが明示的に認めた場合だけ対象です。

[紹介ガイド](https://openroot.dev/referrals)、[builders](builders.md)、[報酬](rewards.md)、[パートナー](partners.md)をご覧ください。

## アフィリエイト試行：追加の20%

規約・プライバシーの版：**2026-10-14-affiliate-1**。[アフィリエイトページ](https://openroot.dev/affiliates)で申請します。自己登録には管理者の承認、その後ポータルでメールコードによる確認が必要です。アフィリエイトのみの参加には GitHub アカウントやプロジェクトは不要です。承認後、専用リンクとコードが表示されます。これは GitHub 組織加入、builder バッジ、プロジェクト権限、非公開申請データを与えません。開発する場合は別途申請します。

Builder は最初の申請でコードを一つ提出します。リンクは追跡 cookie を使わずフォームのコードを入力します。帰属は審査し承認済みアカウントに結び付けるまで申告です。Builder 承認後の最初の**12暦月**に実際に提供された対象報酬について、アフィリエイトは**追加の20%相当の非現金報酬**を得ます。Builder は自分の報酬の**100%**を保持します。登録、未確定マイルストーン、未提供の特典、別の紹介報酬からは発生しません。自己紹介、重複本人情報、承認済み builder への遡及帰属、捏造活動は禁止です。紛争や誤コードは承認前に hello@openroot.dev に連絡し審査を受けてください。

例：実際に提供された対象の EUR 100 API 枠は EUR 20 相当の紹介報酬になり得ます。現金や公式プロバイダー協賛ではありません。提供前に資金付き特典、配布権限、評価額、通貨、有効期限、交換条件を合意します。サブスクリプション等の分割不能特典には合意した価値が必要で、部分的な契約や通貨交換は約束しません。この版には利用可能な残高、自動提供、開かれた交換機能はありません。

宣伝時はアフィリエイト関係を明確に開示し、コミュニティの規則を守り、スパムや報酬保証を避けてください。参加料はありません。規約とプライバシーを別々に受諾し、ニュースレターには登録されません。

Google Cloud に氏名、メール、宣伝計画、同意、審査記録を非公開で保存します。申請は90日後に失効し非同期削除されます。承認後は別の有効な紹介プロフィール、コード、ポータルアカウントを参加中保持し、既存 builder アカウントの期限は延長しません。Resend が承認・ログインの取引メールを処理します。必要なセッション cookie は最大八時間、コードは十分で失効します。識別可能な builder 一覧や非公開プロジェクト情報は渡しません。申請・ポータルにはサイト分析を読み込みません。訂正、終了、削除は hello@openroot.dev へ依頼してください。承認済みプロフィールの終了や未解決の報酬記録は手動審査が必要です。[一般プライバシー通知](https://openroot.dev/privacy)。
