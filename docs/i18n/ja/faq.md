# よくある質問

## 名前は？

OpenRoot 開発者プログラム。参加者は OpenRoot builders です。

## OpenRoot とは？

OpenRoot の中心は、開発者プログラムと builder コミュニティです。役立つオープンソースプロジェクトを対象とし、プログラムの参加者を OpenRoot builders と呼びます。ニュースレターは、プロジェクトや builder の活動、実践的な技術アイデアを紹介することで、この取り組みを支えます。エージェント、自動化、インフラ、AI を活用した 3D を取り上げていますが、プログラムの対象をそれらに限定するものではありません。公開された要件を満たせば、どのソフトウェア分野のプロジェクトでも参加できます。

## 開始済み？

開発者プログラムは開始済みです。申請受付と承認済みアカウント専用の非公開ポータルが利用でき、承認された builders は GitHub Organization に参加できます。報酬の選択肢を広げるパートナーを募集しています。マイルストーンの手動請求を受け付けています。[ポイントと請求手順](rewards.md)を確認し、資金と条件をプロジェクトごとに合意してください。

## 現金報酬？

いいえ。サブスクリプション、クレジット、開発ツールです。

## どのプロジェクトでも参加できる？

どのソフトウェア分野も検討できますが、グループ、権利、安全、行動規則を守る必要があります。OpenRoot がすべて発案・指揮する必要はありません。プログラミング言語や文書言語は自由で、英語以外も歓迎します。アイデア、技術、ロードマップ、方向性は自分で決めます。

## アイデアがなくても申請できる？

はい。「何を作るかまだ決まっていません」にチェックしてください。関心のメモは任意です。OpenRoot は未決定の申請も審査しますが、報酬には具体的な承認済みプロジェクトと合意マイルストーンが必要です。毎回の送信前に現在の申請条件と公開ポリシーを明示的に承諾し、プライバシー同意は別に行います。[申請ルール](builders.md)をご覧ください。

## 非公開で開始できる？

はい。期間や公開条件は参加前に合意し、自動公開タイマーはありません。非公開開発だけでは公開・利用マイルストーンの証拠になりません。他の builders は非公開アクセスを自動取得しません。

## 紹介制度は？

[成果に基づく制度](referrals.md)を予定しています。紹介された builder の承認と対象成果の検証後に、資金付き紹介請求を審査できます。登録だけには報酬を出しません。特典、上限、資金は未確認です。

## 宣伝してくれる？

OpenRoot は刊行物と SNS でメンバーを可能な限り、完全無料で紹介します。広いマーケティングと成長は builders が担当します。掲載、流入、成功は保証しません。

プロジェクトの宣伝は1回の紹介に限定されません。ニュースレターや SNS で、プロジェクトの注目ポイント、作品紹介、詳しい解説記事として複数回取り上げられる場合があります。Builders はリリース、大きな更新、ユーザーの活用事例を hello@openroot.dev に送り、編集側での検討を依頼できます。この支援は完全無料で、報酬の獲得や交換は必要ありません。時期と形式は編集上の適合性と対応可能な範囲によって決まります。OpenRoot は再掲載、リーチ、成果を保証しません。

紹介を提案するには、プロジェクトまたはリリースのリンク、誰に役立つか、変更点、特に取り上げてほしい具体的なポイントと、共有する権限のある任意のスクリーンショットやデモを hello@openroot.dev にメールで送ってください。OpenRoot が編集基準と各プラットフォームのスタイルに合わせて、最終的な投稿を手作業で作成します。依頼は必須ではありません。OpenRoot が独自にメンバーのプロジェクトの公開アップデートを取り上げることもあります。認証情報、機密資料、他の人の個人データは送らないでください。現在はメールで受け付けており、ポータルの専用依頼フォームはまだありません。

OpenRoot は、他の人が使うことを目的としたプロジェクトを開発、または検討している builders を求めています。問題を解決するソフトウェア、便利なツール、ユーザーが何かを実現するためのソフトウェアなどが対象です。ソフトウェアの分野、プログラミング言語、ドキュメントの言語は問いません。既存ユーザーは必要ありません。まだアイデアが決まっていない申請者や、合意した非公開の開発期間も歓迎します。

参加を準備している方や、ハッカソンのプロジェクトを継続している方も歓迎します。対象として事前承認されたハッカソンでの優れた成果に対する追加報酬を計画しています。対象イベント、成果、証拠、資金、ボーナス条件は、報酬付きの募集を始める前に公開し、合意する必要があります。優勝しても OpenRoot のポイントや報酬が自動で付与されるわけではありません。具体的な対象ハッカソンやボーナス額はまだ公表しておらず、ハッカソン追加報酬の請求はまだ利用できません。

## ハッカソンに出られる？

はい。外部共同開発や他の活動もできます。独占参加ではありません。イベント規則とプロジェクト・貢献者の権利を守ってください。

## 初期特典は？

DeepLearning.AI 1か月分が受取まで1件、GPT-6 Astra、Claude Fable 5.1、Gemini 4 Argon 向けの AI モデル API クレジット（予算上限付きの第三者 API アクセスで提供）が USD 20-10,000 相当です。OpenRoot によればキーごとの予算制限が厳格で、数量上限は未公表です。個人 OpenAI/Anthropic/Google/xAI アカウントへのクレジット移転でも公式スポンサーシップでもありません。製品、配布許可、期限、資格、提供は確認待ちで、マイルストーンの手動請求を受け付けています。[詳細](rewards.md)。

パートナーが現在利用可能と報告しているモデルは **GPT-6 Astra、Claude Fable 5.1、Gemini 4 Argon** です。各承認済み特典で利用可否を確認します。後継モデルは API 公開後、パートナーの対応、プロバイダーの条件、同程度の価格が揃う場合に切り替える方針ですが、公開当日の更新は保証しません。価格や条件の大幅な変更によりモデル一覧が変わり、API 利用枠が一時的に提供できない場合があります。承認済みの未使用ポイントは記録を保持し、合意条件に従って他の対象となる利用可能な特典に交換できます。現金ではなく、代替特典の在庫や即時交換を保証しません。カタログ更新によって既存の合意済み報酬を取り消しません。

## スター数で保証される？

所属グループの公開規則だけが資格を定めます。注目は独自経路を持ち、利用増加は別特典につながる場合があります。公開スター表は合意した対象の新規成長に適用します。手動請求は受付中で、過去のスターは別途合意が必要です。承認済みダウンロード・利用表は報酬ガイドに掲載しています。月ごとの数値で一度限りの累計最高レベルを決め、毎月の反復報酬にはしません。利用は意味のある MAU または平均 DAU を選び、連続する完全な2か月で請求レベルを満たします。同じ利用を二重に支払いません。明示的な移行合意がない限り既存合意を維持します。

## 報酬を選べる？

対象グループ・区分の利用可能な対象特典から選ぶ方針です。確認前に特定の契約や販売元を保証しません。

## 誰でもポータルに入れる？

いいえ。申請と承認が必要です。承認でアカウントを作り、ログインは本人を識別するだけで所属を与えません。

## 正確な GitHub 名が必要なのは？

正しいアカウントを探すためです。連携で管理権を確認するので、他人の名前を入力してそのプロジェクトを請求できません。

## メールコードは MFA？

初回メール検証であり、強い独立要素の MFA として扱いません。追加パスキー・認証アプリ要件はアクセス有効化前に説明します。

## 所有権と離脱は？

自分のコードの権利と指揮を保つ方針です。リポジトリは OpenRoot Organization 内にあり、あなたに Admin を与えます。Organization 所有者も管理権を持つため、個人名義リポジトリとは違います。ライセンス、保守、貢献、離脱・移転は参加前に合意します。

## 既存リポジトリを提案できる？

はい。申請は手動審査のため受付中です。元の URL、移管またはコピーの権限、日付付き利用証拠を提出してください。過去実績は承認済みコホートの基準で認められる場合のみ計上します。既存プロジェクトで申請する場合、承認されたプロジェクトを **OpenRootdev** 内でホストする必要があります。審査後に元のリポジトリを移管するか、組織内に空のリポジトリを作り、Git でコードをコピーします。プロジェクトと移行の承認前には移行しないでください。コードのコピーではスター、issue などの GitHub データはコピーされません。既存の利用実績と報酬は別途審査します。[手順を読む](builders.md)。

## 追加アカウントやチームは？

できます。正確な GitHub 名や App 名、人間・機械・連携の種類、目的、対象リポジトリ、ロールを指定してください。専用チームは複数リポジトリを扱えますが、全体書き込み権限は与えません。秘密は含めず、チームと自動化は審査します。

## チーム報酬の分配は？

参加前に合意します。リポジトリ作成、コミット数、最後の統合 PR 作者で自動決定しません。

## スポンサー特典が足りなければ？

資金なしのグループは報酬を約束できません。資金付きグループは明確な容量と在庫予約が必要です。合意した選択肢がなくなれば、公表済みの代替・解決条件に従います。

一般的なお問い合わせは [hello@openroot.dev](mailto:hello@openroot.dev) へお願いします。

## 無料のサンドボックス。アカウントを守りましょう。

OpenRoot は開発と共同作業のためのサンドボックスであり、支払いを求める場所ではありません。パスワード、ログイン・復旧コード、トークン、API キー、支払い情報を送るよう求めたり、参加や報酬の解除に料金を請求したりすることはありません。申請にはメールアドレスと正確な GitHub ユーザー名が必要です。ログインコードは公式ポータルだけに入力し、人には送らないでください。自分のリポジトリの権限内で協力者を招待し、リポジトリ単位のアプリを設定できます。Organization レベルの操作には管理者の対応が必要な場合があります。秘密情報をリポジトリ、申請、メッセージに置かないでください。Organization のホスティングは有料サービスの無制限な無料利用を意味しません。
