# OpenRoot 開発者プログラムのパートナーになる

## 開発を続けるための支援

革新的で実際に使われる GitHub プロジェクトを作る開発者を支援してください。透明で検証済みの成果に対してクレジット、サブスクリプション、ツールを提供します。

小規模で上限のある試行の創設パートナーを募集中です。OpenRoot は[初期特典](rewards.md)を報告していますが、マイルストーンの手動請求は受付中です。資金、提供条件、販売元の許可は発行前に特典ごとに確認します。公式スポンサーシップを示しません。

## 支援方法

- 報酬パートナー：受取人への許可済みライセンス、ギフト契約、直接クレジット。
- グループパートナー：限定プロジェクト数と、明確に上限を設けた報酬在庫。
- 技術パートナー：適切な指導、相談、開発支援。有料賞品に見せかけず、補足支援とします。

資金スポンサーが非現金特典の購入費を出すことも考えられます。別途合意した予算と提供手順が必要です。開発者には現金ではなく特典を渡します。

## 提供できること

合意した試行では透明な謝辞、関連プロジェクトの刊行物・SNS 紹介、公開リンク、確認できる範囲での成果と受取状況の集計報告が可能です。

メンバープロジェクトの宣伝は完全無料で、可能な範囲で行います。参加はハッカソンや他の活動を妨げません。

プロジェクトの宣伝は1回の紹介に限定されません。ニュースレターや SNS で、プロジェクトの注目ポイント、作品紹介、詳しい解説記事として複数回取り上げられる場合があります。Builders はリリース、大きな更新、ユーザーの活用事例を hello@openroot.dev に送り、編集側での検討を依頼できます。この支援は完全無料で、報酬の獲得や交換は必要ありません。時期と形式は編集上の適合性と対応可能な範囲によって決まります。OpenRoot は再掲載、リーチ、成果を保証しません。

紹介を提案するには、プロジェクトまたはリリースのリンク、誰に役立つか、変更点、特に取り上げてほしい具体的なポイントと、共有する権限のある任意のスクリーンショットやデモを hello@openroot.dev にメールで送ってください。OpenRoot が編集基準と各プラットフォームのスタイルに合わせて、最終的な投稿を手作業で作成します。依頼は必須ではありません。OpenRoot が独自にメンバーのプロジェクトの公開アップデートを取り上げることもあります。認証情報、機密資料、他の人の個人データは送らないでください。現在はメールで受け付けており、ポータルの専用依頼フォームはまだありません。

受け手の規模、顧客転換、好意的掲載、独占、申請者メールへのアクセスは保証しません。公開謝辞には許可が必要で、資金提供で成果判断を買うことはできません。

## 小さな約束から

特典、対象人数・プロジェクト数、期間・金額、対象アカウント・国、期限、受取方法、継続請求を伝えてください。提供者はこの成果報酬プログラムでの配布を明示的に許可する必要があります。通常の譲渡不可の登録・スタートアップ向けクレジットは再配布できる賞品ではありません。

## コミュニティハッカソンとアンバサダー

内部コミュニティハッカソンとパートナー支援の公開イベントを計画し、世界各地のパートナー、共同主催者、地域アンバサダーを募集しています。優先したい方向は、ボランティア調整、修理活動、アクセシブルな地域資源一覧など、実際の地域課題に応える再利用可能なオープンソースです。これらはテーマの例であり、発表済みイベント、受益者、賞ではありません。日時、ルール、資金を確保した報酬は募集開始前に公開します。

partner@openroot.dev へのメールで[アンバサダーへの関心をお知らせください](https://openroot.dev/ambassadors)。関心表明は任命でも、OpenRootを代表し、支出や報酬を約束し、リポジトリにアクセスする権限でもありません。役割、経費、報酬の有無、安全対策は事前に合意します。参加者個人がイベント費用を負担することは想定していません。

## 準備中の公共財支援構想

**OpenRoot Public Goods Fund** は準備中の構想であり、独立した法的基金や受付中の寄付制度ではありません。ニュースレター広告、将来のグッズ収入、パートナー支援で公益性のあるオープンソース活動と、それに必要な人員、運営、準備金を支える方針です。収入の固定割合や購読1件ごとの拠出は約束していません。無料購読は読者としての支援であり寄付ではありません。用途を指定したスポンサー資金は合意目的に従います。
