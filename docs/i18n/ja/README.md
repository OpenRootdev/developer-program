# OpenRoot 開発者プログラム

オープンソースプロジェクトを開発中ですか？ あるいはアイデアがありますか？ OpenRoot 開発者プログラムへの参加を申請できます。参加する builders を無料のプロジェクト紹介で支援し、審査されたマイルストーンに対して報酬を得る機会を提供します。

OpenRoot 開発者プログラムは、独立した開発者（**OpenRoot builders**）と、役立つソフトウェアを支援したいパートナーをつなぎます。Builders は **OpenRoot の GitHub Organization** 内で開発し、プロジェクトを成長させます。OpenRoot は刊行物と SNS でメンバーのプロジェクトを可能な限り紹介します。宣伝支援は**完全に無料**ですが、掲載、リーチ、成功は保証しません。パートナーは条件を満たしたプロジェクトにクレジット、サブスクリプション、開発ツールを提供します。

プロジェクトの宣伝は1回の紹介に限定されません。ニュースレターや SNS で、プロジェクトの注目ポイント、作品紹介、詳しい解説記事として複数回取り上げられる場合があります。Builders はリリース、大きな更新、ユーザーの活用事例を hello@openroot.dev に送り、編集側での検討を依頼できます。この支援は完全無料で、報酬の獲得や交換は必要ありません。時期と形式は編集上の適合性と対応可能な範囲によって決まります。OpenRoot は再掲載、リーチ、成果を保証しません。

紹介を提案するには、プロジェクトまたはリリースのリンク、誰に役立つか、変更点、特に取り上げてほしい具体的なポイントと、共有する権限のある任意のスクリーンショットやデモを hello@openroot.dev にメールで送ってください。OpenRoot が編集基準と各プラットフォームのスタイルに合わせて、最終的な投稿を手作業で作成します。依頼は必須ではありません。OpenRoot が独自にメンバーのプロジェクトの公開アップデートを取り上げることもあります。認証情報、機密資料、他の人の個人データは送らないでください。現在はメールで受け付けており、ポータルの専用依頼フォームはまだありません。

OpenRoot は、他の人が使うことを目的としたプロジェクトを開発、または検討している builders を求めています。問題を解決するソフトウェア、便利なツール、ユーザーが何かを実現するためのソフトウェアなどが対象です。ソフトウェアの分野、プログラミング言語、ドキュメントの言語は問いません。既存ユーザーは必要ありません。まだアイデアが決まっていない申請者や、合意した非公開の開発期間も歓迎します。

参加を準備している方や、ハッカソンのプロジェクトを継続している方も歓迎します。対象として事前承認されたハッカソンでの優れた成果に対する追加報酬を計画しています。対象イベント、成果、証拠、資金、ボーナス条件は、報酬付きの募集を始める前に公開し、合意する必要があります。優勝しても OpenRoot のポイントや報酬が自動で付与されるわけではありません。具体的な対象ハッカソンやボーナス額はまだ公表しておらず、ハッカソン追加報酬の請求はまだ利用できません。

自分のアイデアを持ち込めます。分野、プログラミング言語、リポジトリや文書の言語は問いません。英語以外も歓迎します。プロジェクトを主導し、自分のコードの権利を保持できます。非公開での開発期間も認められ、公開条件は参加前に合意します。Organization の所有者は、その配下のリポジトリへの管理権限を保持します。

OpenRoot への参加は独占契約ではありません。イベントの規則やプロジェクトの権利を守りながら、ハッカソン、外部との共同開発、その他の活動に参加できます。

## 現在の状況

プログラムは**開始済み**で、創設パートナーを募集しています。[申請の審査受付を開始しています](https://openroot.dev/apply)。非公開ポータルは承認済みアカウント向けに https://openroot.dev/portal で利用できます。マイルストーンの手動請求を受け付けています。最初の対象スター20件で800ポイントが解放され、承認後に交換できます。発行前に特典ごとの条件を確認します。OpenRoot が報告している初期特典は、DeepLearning.AI の1か月分（受け取りが確定するまで1件のみ）と、GPT-6 Astra、Claude Fable 5.1、Gemini 4 Argon を利用できる、USD 20-10,000 相当の AI モデル API クレジット（予算上限付きの第三者 API アクセスで提供）です。各キーに予算上限があり、API 特典の数量上限は公表していません。学習サービスの正確な製品、配布許可、有効期限、受取人の条件は確認が必要です。OpenAI/Anthropic/Google/xAI の公式スポンサーシップではなく、全員への報酬保証でもありません。有料サブスクリプションや開発ツールを含む、より幅広い特典を近日予定しています。具体的な製品や日付は約束しません。[報酬の詳細](rewards.md)をご覧ください。

パートナーが現在利用可能と報告しているモデルは **GPT-6 Astra、Claude Fable 5.1、Gemini 4 Argon** です。各承認済み特典で利用可否を確認します。後継モデルは API 公開後、パートナーの対応、プロバイダーの条件、同程度の価格が揃う場合に切り替える方針ですが、公開当日の更新は保証しません。価格や条件の大幅な変更によりモデル一覧が変わり、API 利用枠が一時的に提供できない場合があります。承認済みの未使用ポイントは記録を保持し、合意条件に従って他の対象となる利用可能な特典に交換できます。現金ではなく、代替特典の在庫や即時交換を保証しません。カタログ更新によって既存の合意済み報酬を取り消しません。

このリポジトリは公開文書の拠点です。仕組み、FAQ、パートナー募集を掲載します。非公開ポータルや申請者情報は含みません。

## 開発を続けるための支援

AI・クラウドクレジット、有料ツール、その他の実用的な特典を提供するパートナーを歓迎します。規模を限定した試行から始め、実際の成果があるプロジェクトを支援しましょう。

[パートナーになる](https://openroot.dev/partners)、または **partner@openroot.dev** に連絡してください。フォームは端末内でメール下書きを作り、サーバーには送信しません。

一般的なお問い合わせは [hello@openroot.dev](mailto:hello@openroot.dev) へお願いします。

[リポジトリの issues](https://github.com/OpenRootdev/developer-program/issues) で訂正や質問を歓迎します。申請者の個人情報、セキュリティ報告、認証情報、報酬コードは公開しないでください。

## 無料のサンドボックス。アカウントを守りましょう。

OpenRoot は開発と共同作業のためのサンドボックスであり、支払いを求める場所ではありません。パスワード、ログイン・復旧コード、トークン、API キー、支払い情報を送るよう求めたり、参加や報酬の解除に料金を請求したりすることはありません。申請にはメールアドレスと正確な GitHub ユーザー名が必要です。ログインコードは公式ポータルだけに入力し、人には送らないでください。自分のリポジトリの権限内で協力者を招待し、リポジトリ単位のアプリを設定できます。Organization レベルの操作には管理者の対応が必要な場合があります。秘密情報をリポジトリ、申請、メッセージに置かないでください。Organization のホスティングは有料サービスの無制限な無料利用を意味しません。

質問は [hello@openroot.dev](mailto:hello@openroot.dev) へ。[LinkedIn で OpenRoot をフォロー、またはメッセージ](https://www.linkedin.com/company/openroot-dev/)を送れます。GitHub 招待を承認した後、[メンバー限定のクイックスタート](https://github.com/OpenRootdev/GET-STARTED-README)をご覧ください。

## 既存プロジェクトは組織内に置きます

既存プロジェクトで申請する場合、承認されたプロジェクトを **OpenRootdev** 内でホストする必要があります。審査後に元のリポジトリを移管するか、組織内に空のリポジトリを作り、Git でコードをコピーします。プロジェクトと移行の承認前には移行しないでください。コードのコピーではスター、issue などの GitHub データはコピーされません。既存の利用実績と報酬は別途審査します。[手順を読む](builders.md)。

## OpenRoot の支援と今後のイベント

OpenRoot は広告収入とパートナーの支援によって、ビルダーが無料で参加できるプログラムを維持します。[無料のニュースレター](https://openroot.dev/newsletter)を読み、[LinkedIn をフォロー](https://www.linkedin.com/company/openroot-dev/)することで、読者を増やし、支援に関心のあるスポンサーに届きやすくなります。申請や審査対象になるために、購入、有料購読、寄付は必要ありません。GitHub Sponsors は計画中であり、利用可能な支払い手段としてはまだ案内していません。スポンサーシップについては [partner@openroot.dev](mailto:partner@openroot.dev) へお問い合わせください。

パートナーから資金や提供許可のある報酬を得られた際に、内部のビルダー向けハッカソンを開催し、その後は公開ハッカソンも検討したいと考えています。これは将来の計画であり、開催を告知したイベントではありません。日程、参加条件、賞品は募集開始前に公開します。
