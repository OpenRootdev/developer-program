# 计划如何运作

计划按项目成果提供非现金权益，不为工时、提交次数或仅创建仓库支付奖励。

## 申请

在 https://openroot.dev/apply 填写邮箱和准确 GitHub 用户名。项目想法或已有项目链接有助审核。申请不等于批准或奖励承诺。

## 获批并验证身份

批准后会创建待完成加入流程的门户账号，并发送说明邮件。请使用获批邮箱登录 https://openroot.dev/portal，只在该页面输入邮件中的验证码。Kristofer 会在批准门户账号之前手动发送 GitHub 组织邀请。批准后只发送一封欢迎邮件，说明接受邀请和在组织中创建仓库的步骤。自动 GitHub 身份关联、项目指标、完整加入流程及门户自动奖励领取尚不可用。待完成加入流程的账号沿用申请原定的 90 天有效期。批准本身不代表获得有资金保障的奖励。

## 开发与增长

在 OpenRoot GitHub 组织内创建获批项目，约定成果路径。开发者负责开发、维护和更广泛营销。OpenRoot 尽力通过刊物与社交媒体宣传成员项目，完全免费，但不保证报道、流量或采用。项目也可参加黑客松和外部活动。

项目宣传不局限于一次介绍。项目可以通过项目亮点、成果展示和深度文章，在通讯和社交媒体中多次获得介绍。Builders 可以将新版本、重要更新和用户故事发送至 hello@openroot.dev，供编辑评估。这项支持完全免费，无需先获得或兑换奖励。发布时间和形式取决于编辑适配性和可用资源；OpenRoot 不保证重复报道、传播范围或结果。

如需建议介绍某个项目，请发送邮件至 hello@openroot.dev，提供项目或版本链接、受益人群、更新内容、希望重点介绍的具体要点，以及有权分享的可选截图或演示。OpenRoot 会人工撰写最终帖子，使其符合自身的编辑标准和各平台的风格。无需先提交请求：OpenRoot 也可能主动介绍成员项目的公开更新。请勿发送凭据、机密材料或他人的个人数据。目前采用邮件流程，尚无专用的门户申请表。

## 展示进展

未来门户将整合关联仓库、贡献、发布版本和里程碑证据。每项指标说明来源和统计周期。用户数和软件包下载量需要 GitHub 以外的证据。

## 达到里程碑

提交项目规则要求的证据。OpenRoot 核查成果、统计周期及排除活动。超过门槛可能启动审核，但不自动发奖。

## 选择已确认奖励

申请符合有资金支持批次的条款后，从可用非现金目录选择合格选项。奖励记录追踪批准和交付。OpenRoot 报告的[初始权益](rewards.md)已开放里程碑人工领取申请，发放前须确认具体权益条款；公布权益不代表每位 builder 自动享有领取权。

阅读[奖励规则](rewards.md)、[builder 指南](builders.md)或[常见问题](faq.md)。
