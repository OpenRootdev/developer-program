# 里程碑与奖励

奖励帮助 builders 持续开发，是由已确认合作或明确获得资金支持的批次提供的非现金权益。

## 什么成果可以获奖？

项目采用适合自身的成果路径：

- 关注度：自然获得的 GitHub 星标、有意义的外部兴趣或报道。
- 分发：指定周期内的版本/软件包下载、完整克隆或容器镜像拉取。
- 采用：根据约定的有意义的产品使用行为衡量日活跃或月活跃用户（DAU/MAU）。
- 持续使用：相关采用指标保持一段时间。

使用证据必须说明事件、独立用户定义、衡量时间范围和数据来源。GitHub 仓库本身无法衡量产品用户。经构建者同意、按项目限定的 PostHog 或同类工具汇总报告可用于审核。排除机器人、测试和人为制造的活动；DAU/MAU 与下载量不可互换，重叠使用不得重复计入。收集和共享数据须有适当的用户告知、必要的同意及访问控制。指标不会自动产生积分或奖励。

星标代表兴趣，下载代表分发，都不自动等于活跃用户。重复自动化、购买互动或自造增长不构成真实成果。每个批次会公布具体排除项。

## 积分与里程碑领取 / 试点规则，2026 年 10 月 18 日

较早的里程碑对每个合格新增自然 GitHub 星标给予更多积分，随着项目增长，新增星标的积分比率逐渐降低。只有达到下列里程碑并通过人工审核才能解锁积分，任意中间数量不可领取。这些是非现金奖励积分，不是模型 token 或可转让余额。

| 里程碑等级 | 合格星标数 | 累计解锁积分 | 相比上一里程碑新增积分 |
|---|---:|---:|---:|
| 1 | 20 | 800 | 800 |
| 2 | 50 | 1700 | 900 |
| 3 | 100 | 3000 | 1300 |
| 4 | 250 | 6000 | 3000 |
| 5 | 500 | 10000 | 4000 |
| 6 | 1000 | 12500 | 2500 |
| 7 | 2500 | 17500 | 5000 |
| 8 | 5000 | 22500 | 5000 |

**20 个星标解锁 800 积分。** 7 或 19 个合格星标不能领取；30 个仅解锁 20 星里程碑。已入账 800 积分后，达到 50 星只新增 900 积分，累计 1700，不会再次发放全额。跳过早期申请不会丢失合格积分；须扣除同一项目和路径已入账的全部积分。尚未公布超过 5000 星的等级。既有约定奖励不会自动降低或重新计价；更换旧规则须明确约定并核对已入账积分。

此表适用于从项目约定基线开始的合格新增增长，不会自动转换仓库显示的全部星标。在有奖励的项目正式参与前，须约定指标、来源、基线、计量起点与周期、证据、有资金保障的最高奖励及权益条款。历史星标须另行约定，未公布历史折扣。奖励按约定分配给项目或团队，不会为每位协作者重复发放。排除机器人、购买互动、自身或团队刷量、重复取消/添加星标，以及复制项目或计数器间的重复计入。已入账积分不重复发放；不追溯修改有效的既有约定或已接受的申请版本。

**下载量：** 每 100 次合格版本或软件包下载对应 10 积分（USD 1）。须在开始累计前约定来源对应的领取门槛、周期和排除项；此换算不允许任意数量领取。浏览、完整克隆和容器拉取不会自动获得奖励，也不代表产品 DAU/MAU。有意义的 DAU/MAU 可用于审核，但未公布标准积分比率。转入的项目从约定计量起点立即累计合格新增下载和使用，首次申请须等一个月并接受审核；转入前历史不作为新增活动。

**人工领取申请已开放。** 请将组织内仓库 URL、达到的里程碑、带日期的证据及以往领取情况发送至 hello@openroot.dev。OpenRoot 审核证据、扣除已入账积分、确认可用奖励及条款，并在批准后安排兑换。首次获批星标里程碑无需等待下一等级即可兑换，但须遵守已约定的转入等待期。目前 API 换算为 10 积分 = USD 1 非现金 API 额度，不是现金余额，也不保证所有未来奖励采用相同比率。目前没有自动门户钱包或自助兑换。不要发送 API 密钥或账号密码。

## 奖励有哪些？

类别包括 AI/API 访问、GPU 或云资源、付费订阅、IDE 和开发工具。Builders 应可从合格且可用的选项中选择。

### OpenRoot 报告的初始权益 / 2026 年 10 月 18 日

- **DeepLearning.AI：**一个月，**仅一份，领取后即无**。具体产品和兑换条款尚待确认。
- **AI 模型 API 额度：**价值 **USD 20-10,000** 的使用额度，**包括 GPT-6 Astra、Claude Fable 5.1 和 Gemini 4 Argon 模型系列**。OpenRoot 表示每个提供的密钥都有严格预算上限。**未公布权益数量上限**，不意味着无限支出或每人自动获得 USD 10,000。发放前须核实分发授权、有效期、模型、领取资格及交付方式。它是第三方访问，不是向你自己的 OpenAI/Anthropic/Google/xAI 账号转入额度，也不代表这些公司的官方赞助。
- **更多权益即将推出，包括付费订阅和开发工具。**不承诺具体产品、数量或日期。

合作方目前报告可用的模型为 **GPT-6 Astra、Claude Fable 5.1 和 Gemini 4 Argon**，每项获批权益均须确认可用性。我们希望在后继模型 API 发布后切换，但须有合作方支持、符合供应商条款且价格相近；不保证发布当天升级。价格或条款大幅变化可能改变模型列表，或使 API 额度暂时不可用。已获批的未使用积分继续保留，可按约定条款兑换其他符合条件且可用的奖励。积分不是现金，不保证替代库存或即时兑换。目录更新不会取消既有约定奖励。

供应商身份保密；发放前按具体权益确认必要的领取者披露、分发授权、有效期和交付条款。不要在公开文档、申请或 GitHub issues 发布 API 密钥、兑换码或账号凭据。不承诺共享个人账号或转移供应商密钥。开发者里程碑人工领取申请已开放；联盟奖励履行是独立流程，不会因此自动启用。

每个选项必须披露账号资格、服务/时长或额度、有效期、兑换截止时间及后续计费义务。OpenRoot 不要求账号密码，也不分发共享付费账号。

## 选择及使用奖励

里程碑和领取申请获批后，builders 可从项目或批次中合格且可用的权益选择。额度、模型和条款按具体权益确认；USD 20-10,000 并不意味着每位 builder 自动获得最高额度。尽力且完全免费的项目宣传是独立的成员权益，不需要消耗奖励。

项目宣传不局限于一次介绍。项目可以通过项目亮点、成果展示和深度文章，在通讯和社交媒体中多次获得介绍。Builders 可以将新版本、重要更新和用户故事发送至 hello@openroot.dev，供编辑评估。这项支持完全免费，无需先获得或兑换奖励。发布时间和形式取决于编辑适配性和可用资源；OpenRoot 不保证重复报道、传播范围或结果。

我们希望加入的 builders 正在创建或探索供他人使用的项目：能够解决问题、提供实用工具或帮助用户完成任务的软件。欢迎任何软件类别、编程语言和文档语言。项目无需已有用户；尚未确定项目的申请者，以及经约定的私有开发阶段，仍然受到欢迎。

我们也欢迎准备参加黑客松或继续开发黑客松项目的 builders。我们计划为符合条件且事先获批的黑客松中的优秀表现提供额外奖励。符合条件的活动、成果、证据、资金和额外奖励条款，必须在有奖励的方案启动前公布并约定。获胜不会自动获得 OpenRoot 积分或奖励。目前尚未公布具体符合条件的黑客松或额外奖励金额；黑客松额外奖励领取尚未开放。

Hermes、OpenClaw 和 OpenCode 支持自定义供应商或 OpenAI 兼容端点，但尚未使用这些客户端测试实际奖励网关。Cursor 的自备密钥聊天功能须验证客户端、模型和网关；这些额度不包含 Cursor 订阅或 Tab。Codex 要求网关支持 Responses API、流式传输及工具调用对话。Claude Code 要求支持的网关 API 格式，例如 Anthropic Messages。仅兼容 OpenAI Chat Completions 并不能证明兼容 Codex 或 Claude Code。兑换前须确认端点、模型 ID、客户端限制及领取者隐私条款。

参阅 [Codex 网关要求](https://learn.chatgpt.com/docs/enterprise/gateway-compatibility) 和 [Claude Code 网关要求](https://code.claude.com/docs/en/llm-gateway-protocol)。本草案不承诺端到端客户端兼容性。

## 资金与公平

加入有奖励的批次前确认奖励及资金。未获资金支持的兴趣名单不承诺奖励。库存有限时，容量及预留规则从一开始就应明确。

须区分符合规则即保证的奖励，与评选奖或名额限制。不能追溯修改要求以拒绝原本有效的申请。已有项目基线和历史成果是否计入，在加入前确定。

按项目/团队约定分配，不默认按贡献者人数倍增。申请依次经过提交、审核、批准和发放。供应商不提供确认时，可能无法知道是否已兑换。Builders 可请求纠正或复核。

非现金奖励也需要适当会计处理及发放奖励前的辖区审查；本草案不规定税务处理。
