# 里程碑与奖励

奖励帮助 builders 持续开发，是由已确认合作或明确获得资金支持的批次提供的非现金权益。

## 什么成果可以获奖？

项目采用适合自身的成果路径：

- 关注度：自然获得的 GitHub 星标、有意义的外部兴趣或报道。
- 分发：指定周期内的版本/软件包下载、完整克隆或容器镜像拉取。
- 采用：根据约定的有意义的产品使用行为衡量日活跃或月活跃用户（DAU/MAU）。
- 持续使用：相关采用指标保持一段时间。

使用证据必须说明事件、独立用户定义、衡量时间范围和数据来源。GitHub 仓库本身无法衡量产品用户。经构建者同意、按项目限定的 PostHog 或同类工具汇总报告可用于审核。排除机器人、测试和人为制造的活动；DAU/MAU 与下载量不可互换，重叠使用不得重复计入。收集和共享数据须有适当的用户告知、必要的同意及访问控制。指标不会自动产生积分或奖励。

星标代表兴趣，下载代表分发，都不自动等于活跃用户。重复自动化、购买互动或自造增长不构成真实成果。每个批次会公布具体排除项。

数值门槛未定。每个项目须明确指标、来源、基线、门槛、周期、证据要求、审核过程、奖励及领取次数限制。

## 奖励有哪些？

类别包括 AI/API 访问、GPU 或云资源、付费订阅、IDE 和开发工具。Builders 应可从合格且可用的选项中选择。

### OpenRoot 报告的初始权益 / 2026 年 10 月 12 日

- **DeepLearning.AI：**一个月，**仅一份，领取后即无**。具体产品和兑换条款尚待确认。
- **AI 模型 API 额度：**价值 **USD 50-10,000** 的使用额度，**包括 GPT、Claude、Gemini 和 Grok 模型系列**。OpenRoot 表示每个提供的密钥都有严格预算上限。**未公布权益数量上限**，不意味着无限支出或每人自动获得 USD 10,000。发放前须核实分发授权、有效期、模型、领取资格及交付方式。它是第三方访问，不是向你自己的 OpenAI/Anthropic/Google/xAI 账号转入额度，也不代表这些公司的官方赞助。
- **更多权益即将推出，包括付费订阅和开发工具。**不承诺具体产品、数量或日期。

此规划阶段保密供应商身份，但兑换前须约定使领取者能知情使用的必要披露。不要在公开文档、申请或 GitHub issues 发布 API 密钥、兑换码或账号凭据。不承诺共享个人账号或转移供应商密钥。申请已开放供审核，领奖未开放；这些权益不是已确认的推荐奖励。

每个选项必须披露账号资格、服务/时长或额度、有效期、兑换截止时间及后续计费义务。OpenRoot 不要求账号密码，也不分发共享付费账号。

## 选择及使用奖励

里程碑和领取申请获批后，builders 可从项目或批次中合格且可用的权益选择。额度、模型和条款按具体权益确认；USD 50-10,000 并不意味着每位 builder 自动获得最高额度。尽力且完全免费的项目宣传是独立的成员权益，不需要消耗奖励。

项目宣传不局限于一次介绍。项目可以通过项目亮点、成果展示和深度文章，在通讯和社交媒体中多次获得介绍。Builders 可以将新版本、重要更新和用户故事发送至 hello@openroot.dev，供编辑评估。这项支持完全免费，无需先获得或兑换奖励。发布时间和形式取决于编辑适配性和可用资源；OpenRoot 不保证重复报道、传播范围或结果。

我们希望加入的 builders 正在创建或探索供他人使用的项目：能够解决问题、提供实用工具或帮助用户完成任务的软件。欢迎任何软件类别、编程语言和文档语言。项目无需已有用户；尚未确定项目的申请者，以及经约定的私有开发阶段，仍然受到欢迎。

我们也欢迎准备参加黑客松或继续开发黑客松项目的 builders。我们计划为符合条件且事先获批的黑客松中的优秀表现提供额外奖励。符合条件的活动、成果、证据、资金和额外奖励条款，必须在有奖励的方案启动前公布并约定。获胜不会自动获得 OpenRoot 积分或奖励。目前尚未公布具体符合条件的黑客松或额外奖励金额；奖励领取仍未开放。

Hermes、OpenClaw 和 OpenCode 支持自定义供应商或 OpenAI 兼容端点，但尚未使用这些客户端测试实际奖励网关。Cursor 的自备密钥聊天功能须验证客户端、模型和网关；这些额度不包含 Cursor 订阅或 Tab。Codex 要求网关支持 Responses API、流式传输及工具调用对话。Claude Code 要求支持的网关 API 格式，例如 Anthropic Messages。仅兼容 OpenAI Chat Completions 并不能证明兼容 Codex 或 Claude Code。兑换前须确认端点、模型 ID、客户端限制及领取者隐私条款。

参阅 [Codex 网关要求](https://learn.chatgpt.com/docs/enterprise/gateway-compatibility) 和 [Claude Code 网关要求](https://code.claude.com/docs/en/llm-gateway-protocol)。本草案不承诺端到端客户端兼容性。

## 资金与公平

加入有奖励的批次前确认奖励及资金。未获资金支持的兴趣名单不承诺奖励。库存有限时，容量及预留规则从一开始就应明确。

须区分符合规则即保证的奖励，与评选奖或名额限制。不能追溯修改要求以拒绝原本有效的申请。已有项目基线和历史成果是否计入，在加入前确定。

按项目/团队约定分配，不默认按贡献者人数倍增。申请依次经过提交、审核、批准和发放。供应商不提供确认时，可能无法知道是否已兑换。Builders 可请求纠正或复核。

非现金奖励也需要适当会计处理及发放奖励前的辖区审查；本草案不规定税务处理。
