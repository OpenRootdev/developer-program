# 常见问题

## 计划叫什么？

OpenRoot 开发者计划，参与开发者称为 OpenRoot builders。

## OpenRoot 是什么？

OpenRoot 的核心是开发者计划和 builder 社区，面向实用的开源项目。计划参与者称为 OpenRoot builders。新闻通讯通过分享项目、builder 的故事和实用技术思路来支持这些工作。它对智能体、自动化、基础设施和 AI 驱动的 3D 的报道并不限制计划范围：任何符合已公布要求的软件类别都可以参与。

## 已开放吗？

开发者计划已正式启动。申请审核和仅限获批账号的私有门户已可使用，获批 builders 可以加入 GitHub 组织。我们正在寻找合作伙伴以扩大奖励池。里程碑人工领取申请已开放，请参阅[积分、里程碑及领取步骤](rewards.md)。项目资金和具体权益条款须另行约定。

## 奖励是现金吗？

不是。奖励为订阅、额度和开发工具。

## 任何类型项目都能参与吗？

任何软件类别均可审核，须符合批次、权利、安全和行为要求。OpenRoot 不需要创造或主导所有项目。任何编程语言和仓库/文档语言都受欢迎，包括非英语。带上自己的想法，技术栈、路线图和方向由你决定。

## 没有项目想法也能申请吗？

可以。勾选“我还不确定要开发什么”，兴趣说明可留空。OpenRoot 也审核未定项目申请；奖励资格仍要求具体获批项目和约定里程碑。每次提交前须明确接受当前申请条款及已发布政策，与隐私同意分开。[阅读申请规则](builders.md)。

## 可先用私有仓库吗？

可以。私有时长及公开条件在加入前约定，不设自动公开倒计时。私有开发本身不证明公开发布或采用里程碑。其他 builders 不自动获得私有访问。

## 有推荐计划吗？

计划中的[里程碑推荐](referrals.md)要求被推荐 builder 获批且达到核实的合格里程碑，才审核有资金支持的推荐奖励。单纯注册不获奖。权益、上限和资金可用性尚未确认。

## OpenRoot 会宣传项目吗？

会尽力在刊物和社交媒体宣传成员项目，完全免费。Builders 负责更广泛营销和增长。不保证报道、流量或成功。

项目宣传不局限于一次介绍。项目可以通过项目亮点、成果展示和深度文章，在通讯和社交媒体中多次获得介绍。Builders 可以将新版本、重要更新和用户故事发送至 hello@openroot.dev，供编辑评估。这项支持完全免费，无需先获得或兑换奖励。发布时间和形式取决于编辑适配性和可用资源；OpenRoot 不保证重复报道、传播范围或结果。

如需建议介绍某个项目，请发送邮件至 hello@openroot.dev，提供项目或版本链接、受益人群、更新内容、希望重点介绍的具体要点，以及有权分享的可选截图或演示。OpenRoot 会人工撰写最终帖子，使其符合自身的编辑标准和各平台的风格。无需先提交请求：OpenRoot 也可能主动介绍成员项目的公开更新。请勿发送凭据、机密材料或他人的个人数据。目前采用邮件流程，尚无专用的门户申请表。

我们希望加入的 builders 正在创建或探索供他人使用的项目：能够解决问题、提供实用工具或帮助用户完成任务的软件。欢迎任何软件类别、编程语言和文档语言。项目无需已有用户；尚未确定项目的申请者，以及经约定的私有开发阶段，仍然受到欢迎。

我们也欢迎准备参加黑客松或继续开发黑客松项目的 builders。我们计划为符合条件且事先获批的黑客松中的优秀表现提供额外奖励。符合条件的活动、成果、证据、资金和额外奖励条款，必须在有奖励的方案启动前公布并约定。获胜不会自动获得 OpenRoot 积分或奖励。目前尚未公布具体符合条件的黑客松或额外奖励金额；黑客松额外奖励领取尚未开放。

## 能参加黑客松吗？

可以，也能外部协作或参加其他活动。参与不排他。遵守活动规则及项目/贡献者权利。

## 初始权益是什么？

DeepLearning.AI 一个月，仅一份可领取；另有 支持 GPT-6 Astra、Claude Fable 5.1 和 Gemini 4 Argon 的 AI 模型 API 额度，通过设有预算上限的第三方 API 访问提供，价值 USD 20-10,000。OpenRoot 表示每个密钥有严格预算且未公布数量上限。这不是转入个人 OpenAI/Anthropic/Google/xAI 账号的额度或官方赞助。具体产品、分发授权、有效期、资格与交付发放前须按具体权益确认；里程碑人工领取申请已开放。[详情](rewards.md)。

合作方目前报告可用的模型为 **GPT-6 Astra、Claude Fable 5.1 和 Gemini 4 Argon**，每项获批权益均须确认可用性。我们希望在后继模型 API 发布后切换，但须有合作方支持、符合供应商条款且价格相近；不保证发布当天升级。价格或条款大幅变化可能改变模型列表，或使 API 额度暂时不可用。已获批的未使用积分继续保留，可按约定条款兑换其他符合条件且可用的奖励。积分不是现金，不保证替代库存或即时兑换。目录更新不会取消既有约定奖励。

## 星标目标保证领奖吗？

只有已加入批次的公开规则决定资格。关注度可有自己的路径，更强采用可能解锁另一种奖励。已公布的星标表适用于约定的合格新增增长。人工领取已开放；历史星标须另行约定。奖励指南已公布获批的下载与采用积分表。月度数量用于一次性累计最高等级奖励，不是每月重复发放。采用路径须选择有意义的 MAU 或平均 DAU，并连续两个完整月达到所领取等级；重叠使用不重复获奖。除非明确约定迁移，既有项目协议继续有效。

## 可以选择奖励吗？

这是拟定模式：按批次与等级选择合格、可用选项。确认前不保证某个订阅或供应商。

## 任何人能登录门户吗？

不能。必须申请并获批。批准建立账号；登录只验证身份，本身不授予成员资格。

## 为何填写准确 GitHub 用户名？

帮助找到正确账号。后续 GitHub 关联验证控制权，输入他人用户名不能认领其项目。

## 邮箱验证码算 MFA 吗？

它是入门邮箱验证，不应称为强独立多因素验证。额外通行密钥或验证器要求在激活前说明。

## 谁拥有并管理项目？

你保留自己代码的权利，并主导项目。仓库托管在 OpenRootdev 下，创建仓库或通过获批转移带入仓库的成员拥有仓库级 Admin 权限。这不是雇佣开发，也不要求整体转让代码权利。

## 能提交已有仓库吗？

可以，申请已开放供人工审核。提交原 URL、转移或复制权限和带日期的采用证据。过去成果只有在获批群组基线规则允许时才计入。若以已有项目申请，获批项目必须托管在 **OpenRootdev**：审核后转移原仓库，或创建空的组织仓库并用 Git 复制代码。项目与迁移获批前不要迁移。复制代码不会复制星标、议题或其他 GitHub 项目数据。已有采用数据和奖励单独审核。[阅读分步操作指南](builders.md)。

## 可以自行创建仓库及选择协作者吗？

仓库管理员自行决定协作者、项目团队、仓库角色及贡献规则，无需另行获得 OpenRoot 批准。一个项目可以使用多个仓库。其他成员不会自动获得私有代码访问权或仓库写权限。仓库范围的应用遵循 GitHub 的正常权限控制；组织级设置可能需要 OpenRoot 协助。

现有组织成员无需再次申请或另行获得 OpenRoot 批准即可创建新仓库。从零创建的新仓库会自动加入计划，并须遵守计划政策。OpenRoot 会人工审核仓库；如需修改或移除，会联系仓库管理员。随着组织发展，计划引入政策检查机器人，目前尚未启用。加入计划不等于奖励获批：私有项目须先公开，并满足约定的里程碑和资金条件，才能获得奖励。

## 团队奖励如何分配？

在加入前约定。建库、提交数量或最后合并 PR 作者不自动决定分配。

## 赞助奖励不足怎么办？

未获资金的批次不能承诺奖励；已获资金批次需明确容量和预留库存。已约定选项不可用时，按已披露的替代与解决条款处理。

如有一般问题，请联系 [hello@openroot.dev](mailto:hello@openroot.dev)。

## 免费的开发沙盒。保护好你的账号。

OpenRoot 是用于开发与协作的沙盒，不是付款请求。我们绝不会要求你发送密码、登录或恢复验证码、访问令牌、API 密钥、付款信息，也不会收取加入或解锁奖励的费用。申请需要邮箱和准确的 GitHub 用户名；登录验证码只能输入官方门户，不要发送给任何人。你可以在自己仓库的权限范围内邀请协作者并配置仓库级应用；部分组织级操作需要管理员协助。不要在仓库、申请或消息中存放秘密凭据。组织托管不意味着可以无限免费使用付费服务。

问题请联系 [hello@openroot.dev](mailto:hello@openroot.dev)。[在 LinkedIn 关注 OpenRoot 或发送私信](https://www.linkedin.com/company/openroot-dev/)。接受 GitHub 邀请后，请阅读[仅供成员访问的快速入门](https://github.com/OpenRootdev/GET-STARTED-README)。

## 不加入开发者计划，也可以参加社区

你可以加入 OpenRoot 社区，而不必申请开发者计划。在 https://openroot.dev/community 验证你的 GitHub 账户，可选填一个兴趣，并接受社区规则和隐私声明。此流程只会申请以普通组织成员身份加入 Community 团队的邀请。请在 GitHub 上接受邀请以完成加入。它不会创建门户账户、订阅新闻通讯，也不会使仓库获得奖励资格。社区成员可以按照组织现有设置创建仓库，并可在以后申请开发者计划。

社区加入流程会将已验证的 GitHub ID 和用户名、可选兴趣、已接受的规则与隐私声明及邀请状态私密存储在芬兰，最长保留 12 个月。必要的安全浏览器 Cookie 会将 GitHub 验证绑定到你的浏览器，最长 10 分钟。GitHub 根据其自身政策处理授权和邀请接受；OpenRoot 不会要求你发送密码、登录验证码或访问令牌。加入页和回调页不收集可选网站分析数据。如需访问、更正、删除数据或获取成员帮助，请联系 hello@openroot.dev。托管服务会处理技术请求日志。
