# Builder 推荐及联盟试点

此前基于 GitHub 用户名的 builder 推荐草案尚未作为奖励计划启用。下述独立联盟试点自 2026 年 10 月 14 日起接受申请审核；奖励兑换仍未开放。

## 推荐能达到真实里程碑的 builders

拟定方式是在被推荐者获批且达到已核实的合格项目里程碑后认可推荐。仅申请、注册或建库不够。

向希望开发自己想法的人分享[计划指南](https://openroot.dev/program)。申请已开放，申请人可填写推荐者的准确 GitHub 用户名。不包含批量上传联系人或自动邀请。

OpenRoot 分别审核成员资格、项目准入、推荐归属、里程碑证据和有资金支持的推荐领奖。推荐不能绕过审批。新项目和获批已有仓库遵守同样公开的批次规则。

## 公平归属

所填 GitHub 用户名只是声明，不是身份凭证。须确认归属并关联已验证账号 ID。重复或争议推荐需审核。自荐、自动化身份、重复账号及伪造使用量不能增加合格推荐数。

推荐者不能访问其他 builder 的私有项目数据。可见状态须限于已披露信息与约定权限。

## 启动前落实资金和条款

潜在非现金奖励包括获授权额度、订阅和工具。实际选项、推荐者资格、里程碑、权益限制、归属时点、申诉、团队处理、容量及兑换规则须在加入前公布并获得资金支持。不宣布具体数量或门槛。

推荐奖励独立于项目里程碑奖励。分享链接、加入组织或转移已有仓库都不承诺奖励。历史成果仅在获批批次明确接受时计入。

参阅[推荐指南](https://openroot.dev/referrals)、[builder 指南](builders.md)、[奖励](rewards.md)及[合作](partners.md)。

## 联盟试点：额外 20%

联盟条款及隐私版本：**2026-10-14-affiliate-1**。在[联盟页面](https://openroot.dev/affiliates)自行申请，经负责人批准后在门户用邮件验证码验证。仅参与联盟不要求 GitHub 账号或 builder 项目。获批后门户提供专属链接和代码。联盟批准不授予 GitHub 组织成员资格、builder 徽章、项目权限或私有申请数据；开发需另行申请。

Builder 在首次申请中提交一个代码。链接会填写表单代码，不使用联盟追踪 cookie。归属在审核并关联获批 builder 账号前只是声明。对于 builder 获批后首 **12 个日历月**内实际交付的合格奖励，联盟成员获得**额外 20% 的非现金奖励价值**，builder 保留自己奖励的 **100%**。注册、待审核里程碑、未交付权益及其他联盟佣金不产生佣金。禁止自荐、重复身份、对已获批 builder 追溯归属及伪造活动。争议或错误代码须在批准前联系 hello@openroot.dev 由负责人审核。

例如，实际交付的合格 EUR 100 API 额度可产生 EUR 20 联盟奖励价值。这不是现金或官方供应商赞助。发放前须商定有资金支持的权益、交付授权、估值、币种、到期时间及兑换条件。订阅及不可拆分权益需约定价值；不承诺部分订阅或货币兑换。本版本没有可消费钱包、自动发放或开放领奖。

推广时须明确披露联盟关系，遵守社区规则，不发送垃圾推广或承诺保证奖励。参与免费。联盟条款与隐私须分别接受，不会订阅新闻简报。

Google Cloud 私密保存姓名、邮箱、推广计划、同意及审核记录。申请记录在 90 天后到期并异步删除。批准后创建独立的活跃联盟资料、代码及门户账号，参与期间保留；不延长已有 builder 账号的到期时间。Resend 处理事务性批准和登录邮件。必要会话 cookie 最长八小时，验证码十分钟到期。联盟成员看不到可识别 builder 的名单或私有项目详情。申请和门户页不加载网站分析。更正、关闭或删除请联系 hello@openroot.dev；获批资料关闭和未解决奖励记录须人工审核。[一般隐私声明](https://openroot.dev/privacy)。
