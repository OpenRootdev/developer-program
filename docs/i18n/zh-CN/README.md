# OpenRoot 开发者计划

正在开发开源项目，或者有一个项目想法？申请加入 OpenRoot 开发者计划，获得免费的项目宣传支持，并有机会因经审核的里程碑获得奖励。

OpenRoot 开发者计划连接独立开发者（称为 **OpenRoot builders**）与希望支持实用软件的合作伙伴。Builders 在 **OpenRoot 的 GitHub 组织**内开发项目并推动增长。OpenRoot 会尽力通过刊物和社交媒体帮助宣传成员项目，**完全免费**；不保证报道、传播范围或成功。合作伙伴为符合条件的项目提供额度、订阅和开发工具。

项目宣传不局限于一次介绍。项目可以通过项目亮点、成果展示和深度文章，在通讯和社交媒体中多次获得介绍。Builders 可以将新版本、重要更新和用户故事发送至 hello@openroot.dev，供编辑评估。这项支持完全免费，无需先获得或兑换奖励。发布时间和形式取决于编辑适配性和可用资源；OpenRoot 不保证重复报道、传播范围或结果。

如需建议介绍某个项目，请发送邮件至 hello@openroot.dev，提供项目或版本链接、受益人群、更新内容、希望重点介绍的具体要点，以及有权分享的可选截图或演示。OpenRoot 会人工撰写最终帖子，使其符合自身的编辑标准和各平台的风格。无需先提交请求：OpenRoot 也可能主动介绍成员项目的公开更新。请勿发送凭据、机密材料或他人的个人数据。目前采用邮件流程，尚无专用的门户申请表。

我们希望加入的 builders 正在创建或探索供他人使用的项目：能够解决问题、提供实用工具或帮助用户完成任务的软件。欢迎任何软件类别、编程语言和文档语言。项目无需已有用户；尚未确定项目的申请者，以及经约定的私有开发阶段，仍然受到欢迎。

我们也欢迎准备参加黑客松或继续开发黑客松项目的 builders。我们计划为符合条件且事先获批的黑客松中的优秀表现提供额外奖励。符合条件的活动、成果、证据、资金和额外奖励条款，必须在有奖励的方案启动前公布并约定。获胜不会自动获得 OpenRoot 积分或奖励。目前尚未公布具体符合条件的黑客松或额外奖励金额；黑客松额外奖励领取尚未开放。

欢迎自带想法，项目类别、编程语言、仓库及文档语言均不限，也欢迎非英语内容。你主导项目并保留自己代码的权利。可以先进行私有开发；任何公开发布要求须在加入前约定。组织所有者仍具有组织内仓库的管理权限。

项目不必专属于 OpenRoot。你可以参加黑客松、开展外部合作或参与其他活动，同时遵守活动规则及项目相关权利。

## 当前状态

计划**已正式启动**，正在寻找创始合作伙伴。[申请已开放供审核](https://openroot.dev/apply)；私有门户已向获批账号开放：https://openroot.dev/portal；里程碑人工领取申请已开放；首个门槛为 20 个合格星标，解锁 800 积分供获批后兑换；发放前确认具体权益条款。OpenRoot 报告的初始权益包括：DeepLearning.AI 一个月，目前仅一份，领取后即无；以及支持 GPT-6 Astra、Claude Fable 5.1 和 Gemini 4 Argon 的 AI 模型 API 额度，通过设有预算上限的第三方 API 访问提供，价值 USD 20-10,000。每个密钥都有独立预算上限，API 权益未公布数量上限。具体学习产品、分发授权、有效期及领取者条件仍需确认。这不代表 OpenAI/Anthropic/Google/xAI 官方赞助，也不保证每位成员获得奖励。更丰富的权益，包括付费订阅和开发工具，即将推出；不承诺具体产品或日期。参阅[奖励详情](rewards.md)。

合作方目前报告可用的模型为 **GPT-6 Astra、Claude Fable 5.1 和 Gemini 4 Argon**，每项获批权益均须确认可用性。我们希望在后继模型 API 发布后切换，但须有合作方支持、符合供应商条款且价格相近；不保证发布当天升级。价格或条款大幅变化可能改变模型列表，或使 API 额度暂时不可用。已获批的未使用积分继续保留，可按约定条款兑换其他符合条件且可用的奖励。积分不是现金，不保证替代库存或即时兑换。目录更新不会取消既有约定奖励。

本仓库是公开文档中心，说明运作方式、回答问题并邀请合作；不包含私有门户应用或申请人记录。

## 免费的开发沙盒。保护好你的账号。

OpenRoot 是用于开发与协作的沙盒，不是付款请求。我们绝不会要求你发送密码、登录或恢复验证码、访问令牌、API 密钥、付款信息，也不会收取加入或解锁奖励的费用。申请需要邮箱和准确的 GitHub 用户名；登录验证码只能输入官方门户，不要发送给任何人。你可以在自己仓库的权限范围内邀请协作者并配置仓库级应用；部分组织级操作需要管理员协助。不要在仓库、申请或消息中存放秘密凭据。组织托管不意味着可以无限免费使用付费服务。

问题请联系 [hello@openroot.dev](mailto:hello@openroot.dev)。[在 LinkedIn 关注 OpenRoot 或发送私信](https://www.linkedin.com/company/openroot-dev/)。接受 GitHub 邀请后，请阅读[仅供成员访问的快速入门](https://github.com/OpenRootdev/GET-STARTED-README)。

## 已有项目须托管在组织内

若以已有项目申请，获批项目必须托管在 **OpenRootdev**：审核后转移原仓库，或创建空的组织仓库并用 Git 复制代码。项目与迁移获批前不要迁移。复制代码不会复制星标、议题或其他 GitHub 项目数据。已有采用数据和奖励单独审核。[阅读分步操作指南](builders.md)。
