# 与 OpenRoot 开发者计划合作

## 支持 builders 持续开发

支持开发创新且真正被使用的 GitHub 项目的开发者。在项目达到透明、核实的里程碑时提供额度、订阅或工具。

我们为规模有限的试点寻找创始合作伙伴。OpenRoot 报告了[初始权益](rewards.md)，里程碑人工领取申请已开放；资金、交付及供应商授权须在具体权益发放前确认。不表示官方供应商赞助。

## 合作方式

- 奖励伙伴：提供获授权的领取者许可、礼品订阅或直接额度。
- 批次伙伴：为有限项目群提供明确设上限的奖励库存。
- 技术伙伴：相关指导、答疑或项目支持。这些补充计划，不伪装成付费奖励。

可选财务赞助者可以出资购买非现金奖励，但须另行约定预算和交付流程。开发者仍收到权益，不是现金付款。

## 我们可以提供

约定的试点可包含透明致谢、相关项目的刊物/社交媒体报道、公开项目链接，以及可取得时的核实成果和兑换情况汇总报告。

成员项目宣传完全免费，按能力尽力支持。加入不妨碍参加黑客松或其他活动。

项目宣传不局限于一次介绍。项目可以通过项目亮点、成果展示和深度文章，在通讯和社交媒体中多次获得介绍。Builders 可以将新版本、重要更新和用户故事发送至 hello@openroot.dev，供编辑评估。这项支持完全免费，无需先获得或兑换奖励。发布时间和形式取决于编辑适配性和可用资源；OpenRoot 不保证重复报道、传播范围或结果。

不承诺受众规模、客户转化、正面报道、排他性或取得申请人邮箱。公开致谢须经许可；赞助不能购买成果判断的控制权。

## 从小规模承诺开始

告知权益、支持人数或项目数、时长/额度、合格账号与国家、有效期、领取方法及计费义务。供应商须明确授权在按里程碑奖励的计划中分发。普通不可转让的注册或创业额度不是可重新分发的奖池。
